# investigate：假设驱动的根因排查

## 触发

用户描述异常现象（"X 慢了"/"X 报错"）或要求验证断言时。

## 流程

```
理解问题 → 生成假设 → [用户审核·强制] → 逐条测试 → 确定根因 → [用户确认·强制] → 写报告
```

## Step 1: 理解问题

1. 搞清楚：**现象**是什么、**期望**是什么、能**稳定复现**吗、**影响范围**多大
2. 收集环境信息（OS / 版本 / 关键配置），LLM 按需自行决定收集什么
3. 搜索已有知识库：INDEX.md → 领域文档 → 踩坑记录

## Step 2: 生成假设

列出可证伪假设，按可能性排序，标记依赖关系。

> 🛑 **检查点 A（强制暂停）**：输出假设列表后暂停，等待用户确认后才能测试。

## Step 3: 逐条测试

- 一次只测一个假设、一个变量
- 有对照时做 A/B 对比，只改一个条件，其他保持一致
- 优先尝试**证伪**（推翻假设）而非证实
- 每条实验记录：操作 → 预期 → 实际 → 结论

## Step 4: 确定根因

输出：根因（精确到能复现）+ 环境限定 + 排除链 + 证据链。

> 🛑 **检查点 C（强制暂停）**：输出结论后暂停，等待用户确认。

## Step 5: 写报告

报告写入 `XX-领域/docs/investigation/调查-<问题域>.md`，已有同问题域文档则并入。更新领域 INDEX.md。
